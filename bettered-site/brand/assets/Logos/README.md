# Logos

The B-Cross in every approved form. Use these files exactly; never redraw or recolor them.

| File | Use |
|---|---|
| `logo-primary.svg` / `.png` | Primary lockup (Navy, gold core) on white or Paper. PNG is 1200 px wide, transparent, for Word, PowerPoint and email. |
| `logo-reversed.svg` / `.png` | Reversed lockup (white, gold core) on Navy only. |
| `logo-reversed-panel.svg` | Reversed lockup on its own Navy panel, for placing on photos or busy grounds. |
| `mark.svg` / `mark-512.png` | The mark alone, Navy with gold core, on light grounds: avatars, small spaces. |
| `mark-reversed.svg` / `mark-reversed-512.png` | The mark alone, white with gold core, on Navy. |
| `app-icon.svg` / `app-icon-512.png` | The mark on a square Navy tile: social profile pictures, app icons. |
| `favicon.svg` | Browser tab icon (rounded tile; the only rounded shape in the system). |

Inks: Navy #0B1F3A, white #FFFFFF, Signal gold #FFC20E. The wordmark lettering is outlined, so the files look identical everywhere.
